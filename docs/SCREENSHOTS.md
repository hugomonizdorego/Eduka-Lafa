# Screenshots — Lafa 0.3.0

Regenerate after every interface change:

```bash
QT_QPA_PLATFORM=offscreen LAFA_QT=pyqt5 python3 scripts/capture-screenshots.py
```

**These are captures of the running application** (PyQt5 / Qt 5.15, Fusion
style, review mode with the sample learner "Maria", nothing saved or sent),
taken on 2 November 2026. They are not concept images: the owner's design
sheet that guided the look is kept separately in `docs/design/` and is not a
screenshot. Captures 40–42 show the real assistant widgets on a plain
background, not a real Edukasaun OS desktop. Photos in articles are Lafa's
own illustrations, because the offline photo pack needs internet.
