# Screenshot review — LAFA 0.4.0

Generated by `scripts/capture-screenshots.py` using actual Qt widgets and
`QWidget.grab()`. Review mode makes no internet/API calls or saved preference
changes. English is selected for most captures. Capture 16 uses the automatic
system-language setting with an Indonesian system locale. Sample weather and
headlines are labeled.

| Capture | Content |
|---|---|
| 01 | LAFA Desktop conversation/welcome and nine navigation destinations |
| 02 | Actual filename search of four temporary sample documents |
| 03 | Twelve browser sign-in service cards, without authenticated sessions |
| 04 | Offline UI with requests disabled |
| 05 | Actual traditional-outfit companion and cited knowledge bubble on an illustrative desktop |
| 06 | Seventeen activities from the app renderer |
| 07 | Weather/world-news layout with sample fixtures |
| 08 | Learning sources and requested site links |
| 09 | Session reminder UI |
| 10 | Virtual Assistant tab in the dedicated LAFA Settings surface |
| 11 | Timor-Leste sources/topic selection with sample headline rows |
| 12 | Python lesson editor and actual output from the bounded interpreter |
| 13 | Nine traditional-outfit poses, including Tebe-tebe and Bidu |
| 14 | First-activation introduction in the actual companion on an illustrative desktop |
| 15 | Actual native LAFA page factory in a labeled integration test host; launch actions disabled in review mode |
| 16 | Indonesian UI selected automatically from the system locale; explicit public search action visible |
| 17 | AI & language settings tab with optional API preferences |

Captures 05 and 14 are **compositions of actual companion pixels on a painted
background**. They are not screenshots of Edukasaun OS installed on a real
desktop. Capture 10 is LAFA's working settings dialog, not proof of registration
inside the current native Eduka-Settings app. Native host integration is supplied
as source and requires target testing. The same limitation applies to actual
panel walking, compositor transparency and tray placement.
Capture 15 shows the supplied integration widget in a small test host, not the
latest Eduka-Settings application. It verifies the page can be embedded with
the same Qt binding; it does not prove the target OS registered that page.
