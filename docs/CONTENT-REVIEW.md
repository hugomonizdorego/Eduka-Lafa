# Content review (Lafa 0.3.0)

Every encyclopedia item, municipality, place, holiday and word list in 0.3.0
is a **draft** written for Lafa from the sources listed with it. Nothing was
copied; numbers that change carry a year; where sources disagree the text
says so or gives a range. **Teachers and experts should review the drafts
before they are marked `reviewed`.** All per-item notes are in
[REVIEW-NOTES.md](REVIEW-NOTES.md) (generated by `tools/review-notes.py`).

## How the content was made

* Writers followed [CONTENT-SCHEMA.md](CONTENT-SCHEMA.md) and
  [TETUN-STYLE.md](TETUN-STYLE.md) (official Tetun of the Constitution).
* Facts were checked with web searches. **The development sandbox could not
  open the source websites directly** (wikipedia.org, timor-leste.gov.tl,
  timorleste.tl, mafint.org, data.worldbank.org, britannica.com,
  tripadvisor.com, moe.gov.tl were blocked; timor-research.org did not
  resolve), so writers relied on search results and summaries; when the
  search budget ran out, some details came from general knowledge and are
  flagged in `review.notes`.
* The translations into the ASEAN and CPLP languages (Malay, Filipino, Thai,
  Vietnamese, Khmer, Lao, Burmese, Chinese, Tamil, Spanish, French) are
  machine-assisted drafts and need native speakers.

## Marking an item as reviewed

Set `"review": {"status": "reviewed", "notes": "Reviewed by … (date)"}`,
run `python3 tools/check-content.py` and `python3 tools/make-manifest.py`,
and publish the change: installed copies receive it through *Konteúdu foun*.
